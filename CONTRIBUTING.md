# Contributing to ŽyrenClaw

Thank you for your interest in contributing to the Žyren architecture and OpenClaw customization scaffolds.

## How to Contribute

1. **Fork the Repository:** Create a personal fork on GitHub.
2. **Create a Feature Branch:** `git checkout -b feature/your-feature-name`
3. **Commit Cleanly:** Write concise, descriptive commit messages adhering to standard conventions.
4. **Push and PR:** Push your changes to your fork and submit a Pull Request to `main`.
5. **Deterministic Verification:** Ensure all benchmark tests and runtime sanity checks pass before requesting a review.
